# FV3011WG4A — In Memoriam

Hotsite em memória de uma lavadora LG FV3011WG4A que enferrujou com 6 meses de uso e teve o reparo em garantia recusado por "mau uso".

Site estático (HTML único + fotos), publicado na Vercel.

## Depoimentos

Os depoimentos ficam na tabela `public.fv_depoimentos` do projeto Supabase **Burgernomics**.
Novos envios entram com `aprovado = false` e só aparecem no site depois de marcados como `aprovado = true` (Table Editor do Supabase).
